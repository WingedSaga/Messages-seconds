# Сообщения секунды для Android

Откройте эту папку в Android Studio и выберите **Build → Build APK(s)**. Готовый файл появится в `app/build/outputs/apk/debug/app-debug.apk`.

Приложение открывает только `https://wingedsaga.github.io/Messages-seconds/`, запрашивает доступ к микрофону/камере для звонков и добавляет системную кнопку громкой связи в окне звонка.
